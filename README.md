# Software Quality Assurance Project

## COMP 6710 – Fall 2026

### Team Information
**Team Name:** OBRIEN

**Team Member:** Colin O'Brien

### Project Description
This project is being completed for COMP 6710 – Software Quality Assurance at Auburn University during Fall 2026.

The objective is to integrate software quality assurance activities into the existing Slikube Python project.

### Project Objectives
1. Implement automated fuzz testing for 10 Python methods.
2. Integrate forensic logging and evidence collection into 10 Python methods.
3. Implement continuous integration using GitHub Actions.
4. Document testing activities, discovered bugs, results, and lessons learned.

### Project Structure
- `fuzz.py` – Automated fuzz testing script.
- `SQA-REPO.md` – Project report and lessons learned.
- `.github/workflows/` – GitHub Actions continuous integration configuration.
- Slikube Python source files – Existing application code.

### Project Status
Project setup in progress. Fuzzing, forensics, and continuous integration will be implemented and documented throughout development.
